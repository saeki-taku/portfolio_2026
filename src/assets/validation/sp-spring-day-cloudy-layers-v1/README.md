人物の姿勢・足元は採用素材のalphaと完全一致。PCは採用描き直し人物をx940,y455、354×318に登録済みで追加変換不要。SPはv21の座標を維持。人物OFFはtoggleGroups.rinの全ファイルを同時に外す。SPのカップ・植物も各グループ全体を連動。PCカップ単独非表示は未対応。

曇天と拡散光、硬い日差しの影の除去、人物OFFを目視確認。manifest再合成は既存プレビューと完全一致（各レイヤーで8bit丸め）。人物alpha差分0。詳しくはverification.json。

使用マスクはglass-mask-v2.png。旧glass-mask.pngは外景alphaだけから作られた未補正版で、特にPC中央桟を含むため使用不可。v2は外景alpha×(1−室内alpha)から導出。白=許可、黒=除外の輝度マスク。alphaは全面255なのでCSS等では必ずluminanceとして使う。効果は外景直後・室内直前に挿入し、それより上の全前景層で遮蔽する。preview-mask-check.pngの青は効果領域の検査用で実装素材ではない。

この段階は曇り静止画のみ。雨・ガラス滴の見え方、他時間帯でのマスク共用は未検証。晴れ、夕方、夜、就寝後は変更していない。
