# SP春・明け方 縦長レイヤー v1

確認用の静止画候補。1024x2400px、左上原点(0,0)。`manifest.json`の8層を順番に同じ矩形で重ねる。凛も室内の読書灯もない。昼/夕方/起床中の夜/就寝後の縦長版と窓枠・外景alpha・ガラスマスクは同座標。

元の`sp-night-asleep-tall-layers-v1`と同じ窓・街・公園・床を保ち、同位置の昼レイヤーを参照して明度を上げた。空に判定できる部分だけに明け方の青灰色と地平線付近の淡い桃色を反映。PCの明け方画像を色調の参照に用いたが、PC画像からSPの構図を切り出していない。生成ガイドと実際のプロンプトは`inputs/`に保存。建物や人物を生成画像に差し替えていない。

街灯りは就寝後の87群から13群、143画素のみを残した。起床中の19,401点灯画素に対して0.74%。新たな点灯箇所なし。`01a-city-lights.png`を外景の上・窓枠の下に配置する。カップは05/06/09、植物は03/04を各グループでまとめて切替。人物レイヤーは存在しない。

全8層のalphaは就寝後/昼の同名レイヤーと一致。全体、街灯りOFF、カップOFF、植物/カップOFFは再合成差分0、透過穴0。左壁の植物用下地の色境界を背後の壁と揃えた。`verification.json`と`final-check.json`を参照。`compare-night-dawn-day.png`は左から就寝後/明け方/昼。

`glass-mask.png`は輝度マスク（白=ガラス、黒=除外）。右窓台と床の方向性のある影は弱めたが、淡く残る。完全な影なし版ではない。仮の時刻は05:00-05:59 JSTで、実サイトの自動切替・セーフエリア・曇り/雨の照明は未検証。既存素材は変更していない。
