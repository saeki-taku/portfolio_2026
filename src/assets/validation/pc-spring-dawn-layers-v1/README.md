# PC春・明け方レイヤー v1

確認用の静止画候補。1345x1170px、左上原点(0,0)。`manifest.json`の4層を順番に同じ矩形で重ねる。凛も室内の読書灯もない。

元の`pc-spring-night-asleep-layers-v1`と同じ窓・街・公園・床の構図を保ち、同位置の昼レイヤーを参照して明度を上げた。空に判定できる画素に限り生成した色ガイドをなじませ、青灰色から地平線付近の淡い桃色へ移る。生成画像の建物・窓枠・室内の形を採用していない。ガイドは`inputs/dawn-paint-guide.png`、実行したプロンプトは`inputs/prompt.txt`。

街灯りは就寝後の35群から3群、9画素のみを残した。起床中の10,072点灯画素に対して0.09%。新たな明かりを足していない。`01a-city-lights.png`を外景と室内の間に配置し、不要なら`preview-city-lights-off.png`の状態にもできる。

`glass-mask.png`は輝度マスク（白=ガラス）。窓・外景・室内・カップのalphaは元就寝後/昼の同名レイヤーと一致。全体と街灯りOFFのプレビューは再合成差分0、透過穴0。`verification.json`と`final-check.json`を参照。`compare-night-dawn-day.png`は左から就寝後/明け方/昼。

右窓台と床の広い斜め影は朝の環境光に合わせて弱めたが、淡い方向性は残る。完全に影をなくした版ではない。PCのカップは一部が室内レイヤーに焼き込まれており、独立切替できない。

仮の時刻は05:00-05:59 JST。時刻切替や季節ごとの日の出補正はサイトに未実装。曇り・雨は別途照明確認が必要。既存の就寝後・昼画像は変更していない。
