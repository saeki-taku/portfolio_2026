# ennui PC spring/day layer separation v1

2026-10-01。分離検証用の初稿。採用原本とNotion・実装は未変更。夕方・夜・SPは対象外。

## 原本・座標

原本: `../b-spring-rin-pc-corner-soft-v4.png`

全納品PNGは1345×1170px、左上原点(0,0)、等倍・同位置。透明余白の切り詰めなし。画像生成でマスクと隠れた部分の補完候補を制作し、Sharpで原本RGBの抽出・限定合成・寸法正規化を実施。原本自体は変更していない。

## 素材と重ね順（下から上）

1. `01-exterior.png`: 空・街・公園。窓の周辺を含むx270..1301 / y178..733を収録。中央枠、人物、鉢植えの背後を推定補完。外周は透明。
2. `02-interior.png`: 壁・窓枠・窓台・床・鉢植え・カップ。ガラス開口は透過。人物とその接触影を除いた窓台を補完。
3. `04-contact-shadow.png`: 人物由来の接触影の近似。窓台上x926..1298 / y730..777の補完範囲内に限定。原本と補完の暗さの差から推定した青灰色の半透明影であり、厳密な光学的分離ではない。
4. `03-rin.png`: 凛・ペン・スケッチブック。生成した輪郭マスクを用い、色は原本RGBをそのまま抽出。顔や服を描き直していない。
5. `05-cup-foreground.png`: 室内小物であるカップを人物より前へ再描画する補助レイヤー。室内側にも保持。カップの持ち手内側とスカートの重なりは要精査。

人物を消す場合は03と04を同時に非表示にする。05は室内小物として残せる。窓枠は今回の固定姿勢では02で対応し、追加の枠前景は作成していない。

## 保持と補完の範囲

- 原本の見える街並みは原則そのまま抽出。人物輪郭の周囲14pxの余裕を含む範囲のみ、人物なし補完画像を使用。窓・人物の移動や拡大縮小はしていない。
- ガラス開口はy187..717、左x281..794、右x816..1288で制限し、下窓枠を外景が上書きしないよう保護した。
- 人物周辺以外の室内、床、壁、窓台は原本画素を保持。人物を消した跡には窓台と外景を推定補完。
- 人物・植物・中央枠で隠れた景色は原本から復元できないため推定であり、元の正解を保証しない。

## 検証結果と残る課題

- 合成プレビューは1,573,650画素中22,361画素が原本と異なる。約98.58%の画素が一致。平均絶対RGB差は0.244/255。これは画質の合格判定ではなく差分の範囲を示す値。
- 画像全体の構図・色・筆跡を保つ試作として成立するが、完全一致や本番採用は未達。
- 生成マスクは厳密な手作業パスではない。人物の髪先・ペン・スカート輪郭、鉢植えの葉・茎・花、窓枠内縁には背景色の縁取りや切り残しがあり、別の外景に切り替える前に精密なマスク調整が必要。
- 人物なし背景に人物全体の残像はないが、補完域の建物・筆致の接続と、カップ周囲の残存色は要確認。接触影も近似である。
- カップで隠れたスカートは描き足していない。今回の同じ姿勢・カップ位置では前景で隠せるが、人物移動や別姿勢への流用は不可。
- 01は室内で隠れる範囲だけ補完している。部屋や窓の移動、パララックス用の広い背景ではない。
