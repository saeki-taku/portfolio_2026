# PC春・晴れの時刻切替（確認用）

2026-10-05。PCの春・晴れを東京時刻で昼、夕方、夜（凛が起きている）、夜（就寝後・凛不在）の4状態から自動選択する。設定パネルでは手動選択と自動への復帰が可能。閾値は `src/lib/scene-time.ts` にまとめた暫定値で、06:00–16:59が昼、17:00–18:59が夕方、19:00–22:59が起きている夜、23:00–05:59が就寝後。開いたままのページは分境界と再表示時に判定し直す。

夜の2素材は `design-proposals/pc-spring-night-clear-v1/` の完成画像を変更せず `src/assets/validation/pc-spring-night-clear-v1/` に複製した。両方1345×1170。外景・室内・人物の正式な分離レイヤーではなく、夜の人物有無は2枚の切替として扱う。昼だけ既存のレイヤー操作を使え、夕方・夜はレイヤー操作を無効化する。HTMLのロゴとナビは画像とは別の要素を維持し、夜のロゴ文字色だけ明るくした。

SP夕方・夜の専用素材はないため、SPでは従来の昼専用構図を表示し、開発用UIに未対応を表示する。季節と晴れは固定。季節判定、実天気API、SP夕方・夜、本番公開は対象外。昼・夕方・夜の外景細部の差は完成画像v1由来で、共通の外景マスターと正式分離レイヤーの制作待ち。

検証：`npm run check`、`npm run build`、`npm run build:dev-preview`、`ENNUI_TEST_URL=http://127.0.0.1:4503 node scripts/verify-scene-time.mjs`、`ENNUI_TEST_URL=http://127.0.0.1:4503 npm run test:local`。固定時計で全4状態の初期表示、06:00・17:00・19:00・23:00の境界、17:00をまたぐ開いたページ、手動から自動への復帰、SP表示を確認。夜2状態を1440×900、1920×1080、1024×821で撮影し、画像・画角の一致とロゴ・ナビの位置を確認した。スクリーンショットは `artifacts/pc-spring-night-clear-v1/`（Git無視対象）。

コミット・プッシュ・本番公開はしていない。
