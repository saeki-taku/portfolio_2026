# 秋背景制作 v1

5時間帯×晴/曇/雨×PC/SP、30背景。夏の同時間・天候の空室背景を編集元とし、街・建物・窓・窓台v9・床壁境界は保持。外の樹木のみ落ち着いた紅葉（黄土・赤銅・くすみ赤、少量の常緑）にする。人物、小物、雨筋、雷線を焼き込まない。昼晴れから順次保存・目視・実装引渡し。人物は春承認の長袖正本を別層として利用、照明は対応背景へ合わせる。秋雷雨は対象外。

生成済みは候補であり、実装・PC/SP切替検証まではサイト完了としない。

## 2026-11-10 背景制作・引渡し実績

5時間帯 × 晴/曇/雨 × PC/SP の30背景を保存・原画目視済み。manifest.jsonのSHAを照合して取り込むこと。PCは1345×1170（昼曇のみ入力と同じ1345×1169）、SPは819×1920。入力30枚・生成プロンプト・生成原本パスをinventory.json / prompts.jsonに保存。

昼は晴の直射光、曇雨の拡散光を区別。明け方は消灯した青紫、夕方は晴の金色と曇雨の弱い暖色、夜在室は室内右側灯と街の点灯、就寝は室内・街とも消灯した深い青灰色。全て人物・鉢・杯を背景に焼き込まず、雨筋・雷線も含めない。人物・小物は実装担当が独立登録する。

PC明け方雨の初稿にあった雨筋はimagegenで除去し差し替えた。SP夜在室晴の初稿にあった鉢片は、空室の夜在室曇を編集元として晴空へ変更し差し替えた。旧版はrejected/へ隔離、現manifestは修正版を指す。

時間帯ごとにimplementationへ直接引渡し。背景30枚完成はサイト全体完了を意味しない。独立層登録・PC/SP画角・全切替・雨遮蔽・回帰・check/build・接続の最終検証は実装側で継続する。
