# 春・夜／就寝後 PC/SP 分離レイヤー実装（確認用）

2026-10-12。`design-proposals/` の `pc-spring-night-awake-layers-v1`、`sp-spring-night-awake-layers-v1`、`pc-spring-night-asleep-layers-v1`、`sp-spring-night-asleep-layers-v1` の README と manifest を読み、画像を変更せず同名の `src/assets/validation/` に複製した。PCは1345×1170、SPは1024×1997。各セットのmanifest順をそのまま使い、全層を同一座標に重ねている。建物の点灯層は各外景の上、室内・窓枠の下に置いた。

PC夜の旧一枚絵とSP夜の昼フォールバックを置き換えた。昼PC描き直し版、昼SP v21、夕方PC/SPは維持。東京時刻の暫定境界は昼06:00、夕方17:00、起きている夜19:00、就寝後23:00で変更なし。開発用パネルの手動選択と通常ページの自動選択の両方でPC/SPの4状態を表示する。季節・天気APIは追加していない。

起きている夜の人物操作はPCで接触影・凛・輪郭補完の3層、SPで連動下地・凛の2層を一緒に切り替える。就寝後の素材には人物層がなく、開発用パネルの人物操作を無効にした。PC夕方・夜のカップ単独切替は素材上成立せず、設定画面で無効にする。SPではカップ・植物とその連動下地を切り替えられる。HTMLロゴは夜に明色を使い、ナビは画像の外に保持した。

素材コピーのSHA256、全層の寸法とアルファ、付属合成プレビューとの原寸再合成を検証した。通常／人物なしの各合成は最大1階調差。点灯レイヤーの非透明ピクセルはPCで起床中10,072から就寝後585（約6%）、SPで19,401から1,916（約10%）へ減っている。これは点灯ピクセル数であり、画面全体の明るさの比率ではない。

Chromeで起きている夜と就寝後をPC 1440×900・1920×1080・1024×821、SP 390×844・430×932・768×1024で撮影。全層の表示矩形一致、夜ロゴ、ナビ、人物と影の連動、人物なしの残像、就寝後の室内灯と街の消灯を確認した。画像は `artifacts/night-layers-v1/`。時刻境界と手動／自動の4状態、夕方・昼の回帰も確認した。`npm run check`、`npm run build`、`npm run build:dev-preview`、夜・夕方・昼・時刻・ローカルの関連テストを実行。

4セットとも `review-candidate`。起きている夜は、決定済みの「本を読む姿勢」ではなく昼から引き継いだスケッチ姿勢。PCの人物も採用PC昼の描き直し凛とは別のv4由来素材。室内の読書灯風の暖色と夜景は固定の画素で、動く光源・季節・天気には未対応。素材の見た目はCSSで描き直していない。
