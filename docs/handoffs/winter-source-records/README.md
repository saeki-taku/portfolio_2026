# 冬背景 v1

5時間帯×晴曇雨雪×PC/SP=40背景。秋の完成済み同構図・同時間帯・同天気の空室を入力にし、雪は曇りを入力とする。晴曇雨は積雪なしの冬枯れ、雪は屋外のみ薄積雪。室内乾燥、人物/鉢/杯/雨筋/雪粒/雷線を焼き込まない。夜在室のみ室内灯と街灯点灯、明け方/就寝は消灯。人物小物と降雪canvasは実装担当が独立登録する。

生成はbuilt-in imagegen、出力確認後candidate-reviewedでmanifestへ登録。素材完成とサイト検証完了は区別する。入力とSHAはinventory.json、実プロンプトはprompts.jsonへ保存する。

## 2026-11-10 制作実績

40背景をbuilt-in imagegenで生成・保存・原画目視確認し、時間帯ごとに実装担当へ直接引渡し。全20シーンPC/SPの候補が揃った。明け方3枚の通信失敗は再試行済み。生成成功40件のプロンプトと原本パスをprompts.jsonへ保存。manifest.jsonは各素材SHAと寸法を記録。晴/曇/雨は積雪なし、雪だけ屋外薄積雪。全素材で独立物・雨筋・雪粒の焼き込みなしを確認。

サイト統合/雨雪遮蔽/全切替/PCSP/回帰/check/buildは実装担当の工程。PCwide独立目視は最終撮影確定後に実施し別記録へ保存する。素材完成のみでサイト完了としない。
