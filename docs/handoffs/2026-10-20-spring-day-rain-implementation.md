# ennui 春・昼・雨 PC/SP 確認用実装

2026-10-20。指定の既存worktreeで作業。コミット、プッシュ、本番公開は未実施。

## 実装

- `pc-spring-day-rain-layers-v2` と `sp-spring-day-rain-tall-layers-v1` の必要な静止層・雨効果を `src/assets/validation/` に版付きで複製。元素材、晴れ、曇りを変更していない。
- 春・昼・雨をPC/SPのシーン候補に登録。開発用「シーン設定」で手動選択できる。自動時刻切替は従来どおり春・晴れ固定で、実天気APIには接続していない。
- manifestの静止層を共通座標で重ね、屋外雨筋とガラス滴の切り抜き済み画像を最上層に重ねる。人物OFF時は人物・接触影・下地を消して `rin-off` の雨画像へ、SP植物OFF時は植物下地と本体を消して `plant-off` の雨画像へ切り替える。カップは既存の連動操作を維持。
- 開発用設定に屋外雨筋とガラス滴の強度スライダー（0–100%）を追加。静止素材の不透明度と、追加した動く雨の濃さを連動させる。
- `rain-motion.ts` で屋外雨筋を下方向に流し、ガラス滴をゆっくり移動。動く描画は固定のalphaマスクで毎フレーム切り抜く。元の切り抜き済みPNGを移動させないため、窓枠・人物・植物の遮蔽が動かない。PC人物ON/OFF、SP人物/植物ON/OFFの6種のマスクを使用。
- 雨以外のシーン、非表示タブ、強度0では描画停止。`prefers-reduced-motion: reduce` では動く描画を停止し、切り抜き済み静止雨だけ表示する。

## 検証

- 素材コピーのSHA-256一致、PC 2状態・SP 4状態の再合成と付属プレビューの画素一致を確認。素材側 `verification.json` は雨漏れ0、窓形状差0、透明穴0、SP植物下地で雨を遮っていた23,687画素の解消を記録。
- PlaywrightでPC 1600×900、1366×768、1080×1000、SP 393×852、320×568、768×1024を撮影。表示中の層は同一寸法・位置。雨効果は状態ごとに屋外とガラスの2層だけ表示。人物/植物OFF、効果OFF、晴れ/曇り/雨切替を確認。
- 別のブラウザ検証でPC/SPの450ms間隔の2フレームを撮影し、PC 15,596画素、SP 3,365画素の画素変化を確認。Canvasの雨が固定alphaマスク外へ出た画素はPC/SP・人物/植物OFF後とも0。雨以外・非表示タブ・reduced-motion・強度0で停止、解除後再開も確認。時間差画像は `artifacts/rain-motion/`。
- 原寸素材との比較とスクリーンショット目視では、人物・窓枠・室内への雨漏れ、SP植物付近の矩形遮蔽、人物OFFの残像は見えない。PCのカップ単独OFFは素材上未対応。
- 既存のSP曇り、明け方、夕方、夜起床中、夜就寝後、時刻切替の回帰スクリプトが通過。`npm run check`、`npm run build`、`npm run test:local` が通過。

## 2026-10-20 降雨感の微調整

屋外の動く雨筋をPC 100→140本、SP 150→205本へ増やし、遠景の細く短い線と近景のやや長く速い線を混ぜた。ガラス滴の数と速度、固定alphaマスク、強度設定は維持。調整前の時間差画像は `artifacts/rain-motion/before/`、調整後は `artifacts/rain-motion/` に保存。450ms間の変化画素数はPC 15,596→24,437、SP 3,365→5,596。人物・植物切替後も動く雨の固定マスク外漏れは0。

## 2026-10-20 細線・高密度への再調整

ユーザー指定の「細かい線を多く」に合わせ、上記のやや長く明るい近景案をさらに調整。動く雨筋はPC 320本・SP 450本。約8割を細く短い遠景、約2割を少し速い近景とし、幅・長さ・速度・透明度を分散した。元の静止雨筋は屋外72%、ガラス滴85%の不透明度で下支えし、細い動線を見やすくした。ガラス滴の動く描画数・速度は変更していない。`artifacts/rain-motion/before-fine/` と `artifacts/rain-motion/` に前後の時間差画像を保存。原寸拡大は同ディレクトリの `before-fine-*-detail.png` / `after-fine-*-detail.png`。

PC/SPともアニメーション・人物/植物切替後の固定マスク外漏れ0、reduced-motionと非表示タブの停止、雨以外の停止を再確認。headless Chromeの2秒計測ではPC/SPとも121回の表示更新、50ms以上のLong Taskは0。ただし実機の電池消費や低性能端末の負荷は未測定。短い録画はPlaywrightのffmpeg実行ファイルが環境にないため作成せず、時間差画像を証拠として残した。

## 2026-10-20 大雨への範囲拡張

開発用の屋外雨筋・ガラス滴の独立スライダーを0–200%に拡張。100%を従来の通常雨として保持し、0–100%では動く線/滴の本数・速度・長さ・濃さを連続的に下げる。100–200%では細線の本数をPC 320→1,500、SP 450→2,100へ増やし、速度と長さを控えめに上げる。動くガラス滴はPC 26→78、SP 38→114。最大に近づくほど窓外だけに薄い青灰色の雨かすみをかけ、白い幕や太い線に頼らず大雨を表現する。元の静止雨素材は不透明度1を上限とし、強度0では非表示。窓・人物・植物の固定alphaマスクは全強度で共有する。

`scripts/verify-rain-motion.mjs` で弱雨40%、通常100%、大雨200%のPC/SP表示を撮影。通常は `artifacts/rain-motion/{pc,sp}-frame-*.png`、最大は `*-heavy-frame-*.png`、弱雨は `*-weak.png`。最大時のCanvas有色画素は通常の1.25倍以上、450ms間のフレーム差あり。人物・植物OFF後を含めマスク外の雨は0画素。雨以外・非表示タブ・reduced-motion停止、強度0の停止と復帰も通過。PC/SPそれぞれ通常/最大を2秒計測し、表示更新121–122回、50ms以上のLong Task 0。低性能の実機での負荷は未測定。

## 2026-10-20 通常から大雨まで再増量・高速化

最新の確認指示に合わせ、通常雨もPC 320→420本、SP 450→620本、最大雨はPC 1,500→2,100本、SP 2,100→3,000本へ引き上げた。弱雨も通常本数に比例して増える。落下速度倍率は通常1.18、最大2.2（直前は通常1.0、最大1.7）。線幅は据え置き、長さは最大で元線の1.3倍。窓外のかすみは最大9%に抑え、ガラス滴は補助として最大PC 90・SP 135点。

直前の通常/最大画像は `artifacts/rain-motion/before-more-rain/`、最新版は同ディレクトリ直下の `*-frame-*.png` / `*-heavy-frame-*.png`。PC/SPの450ms差、弱雨/通常/最大の密度差、人物/植物OFF・固定マスク漏れ0、独立スライダー、強度0、reduced-motion、非表示停止を再確認。headless Chromeの2秒計測はPC/SPの通常/最大すべて表示更新121回、50ms以上のLong Task 0。実機の負荷は未測定。
