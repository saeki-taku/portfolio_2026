# SP春・夕方 縦長分離素材の受け入れ準備

2026-10-17更新: 素材受領・本体組み込み・画面検証は完了。結果は `2026-10-17-sp-evening-tall-implementation.md` を参照。以下は受け入れ前の準備記録。

2026-10-16時点で1024×2400pxの夕方分離素材は未受領。現行の夕方は `design-proposals/sp-spring-evening-pose-layers-v2/` の1024×1997pxを表示している。晴れ昼だけが `design-proposals/sp-day-tall-layers-v1/` の1024×2400pxへ移行済み。旧夕方素材を縦に引き伸ばしたり、昼の人物・影・下地を夕方へ流用したりしない。

受領待ち: 完成報告、新しい版付きフォルダのREADME・manifest、manifest記載の全レイヤー、通常合成と人物OFFのプレビュー、検証結果。全層の1024×2400px・RGBA・左上原点(0,0)・透明余白、重ね順、連動トグル群を確認する。夕方ポーズ、夕方の色、窓・人物・カップ・植物の位置を、承認済み夕方と新しい昼の共通座標の両方に照らして確認する。原寸再合成とプレビューを画素比較し、人物OFFで人物・接触影・人物由来の下地が残らず、カップと植物が残ることを確認する。素材側の継ぎ目をCSSの影や個別位置調整で隠さない。

受け入れ後は版付きコピーを `src/assets/validation/` に置き、`src/pages/index.astro` のSP晴れ夕方だけを新層へ変更する。`layout()` の縦長対象をSP晴れ昼と晴れ夕方へ広げ、どちらも横倍率 `画面幅 / 1024`、高さ `2400 × 倍率`、上端0、全層同一矩形とする。PC、SP曇り昼、夜、就寝後の旧1997px表示は維持する。時刻による昼⇄夕方遷移と手動シーン設定の再配置も確認する。

確認画角は393×852、393×900、393×760（下部34px safe-area模擬）、390×844、430×932、320×568、768×1024。昼と夕方の窓枠・窓台・人物の座標一致、全幅表示、人物ON/OFF、カップとノートの前後関係、PCと未移行SPシーンの回帰を撮影する。`npm run check`、`npm run build`、ローカルE2Eも実行する。コミット・プッシュ・公開はしない。

固定メニューの現状: 晴れ昼の393×852、390×844、393×760（下部34px模擬）では床の上だけに重なる。320×568ではメニューが人物の膝・足とカップの高さまで上がって重なり、床だけに収まらない。768×1024では画面の縦が絵より短いため窓下部が画面外となり、メニューは窓の景色に重なる。夕方でも同じ位置関係を実測し、素材実装のずれとUIレイアウトの問題を区別して報告する。
