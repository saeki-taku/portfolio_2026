# 春・明け方・曇り PC/SP 受け入れ準備

2026-10-20。受け入れ前に定めた確認項目。素材の受領・実装結果は `2026-10-20-spring-dawn-cloudy-implementation.md` を参照。既存worktreeの未コミット変更を保持し、コミット・プッシュ・本番公開はしない。

## 基準と受け入れ条件

- PCは `pc-spring-dawn-layers-v1` と同じ1345×1170、SPは `sp-spring-dawn-tall-layers-v1` と同じ1024×2400。全層RGBA、左上原点(0,0)、透明余白を維持し、共通親で同じ倍率/位置に重ねる。
- README、manifest、記載全層、通常プレビュー、検証記録が揃ってから導入。原本から版付きフォルダへコピーし、コピーSHA-256、寸法、各表示状態の原寸再合成を照合する。
- 人物・接触影・室内読書灯は表示しない。受領素材の微小な街灯りは採用済み晴れ明け方と同一で、原本を変えずに維持する。PCカップの単独OFFは既存素材上未対応。SPの植物とカップは下地を含めて連動する。
- 晴れ明け方と窓四辺・外景/室内alpha・街/公園/鉢植え/カップ/窓台の座標を比較。SPは他の縦長シーンとガラスマスクも照合。空と室内の曇り光を晴れ/曇り昼との時間帯の連続性で目視確認し、画像の差をCSS補正で隠さない。

## サイト接続後の検証

- PC/SPだけに `spring-dawn-cloudy` を登録。開発用シーン設定で「春・明け方・曇り」を手動選択できることを確認。自動表示は従来どおり東京時刻05:00–05:59の春・晴れ固定で、実天気には連動しない。04:59就寝後、05:00明け方、05:59明け方、06:00昼の境界を回帰する。
- PC 1440×900、1920×1080、1024×821、SP 393×852、393×760、320×568、768×1024を撮影。晴れ⇄曇りの親矩形・窓枠・ロゴ・メニュー位置、人物/照明なし、SPカップ/植物ON-OFF、PC/SPの横はみ出しとメニュー到達性を確認。
- 春昼の晴れ/曇り/雨、特に雨の最新密度・速度・人物/植物マスク・強度0/200%・reduced-motionを回帰。`npm run check`、`npm run build`、ビルド後の`npm run test:local`を実行し、確認URLとスクリーンショットを記録する。

明け方の雨や夕方/夜/就寝後の曇り・雨は、この素材から流用しない。
