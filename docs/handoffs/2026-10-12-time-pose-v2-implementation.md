# 夕方・起きている夜の人物姿勢 v2 確認用実装

2026-10-12。`design-proposals/time-pose-candidates-v2-handoff.md` と4セットのREADME・manifestを確認し、夕方PC/SP、起きている夜PC/SPを `*-pose-layers-v2` に切り替えた。各セットを変更せず `src/assets/validation/` に複製した。PC昼の採用描き直し版、SP昼v21、PC/SP就寝後の消灯素材は保持している。旧夕方・夜v1も比較用素材として保持しているが、現在の表示には使わない。

v2はPC1345×1170、SP1024×1997の共通座標。manifest順で背景、必要なら街灯り、室内・下地、新しい接触影、人物、カップ前景を重ねる。旧03-rin・04-contact-shadow・06-person-edge-restore、SPの旧07/08下地と人物はv2シーンに入れない。人物OFFでは新しい人物と影を同時に隠す。PCのカップ単独切替不可とSPのカップ・植物連動は従来の素材制約どおり。

夕方はペンを置き、閉じたスケッチブックに手を休めて外を見る姿勢。夜は青灰色の部屋着で開いた本を両手に持ち読む姿勢。夕方・夜ともPC/SPの背景層は各v1とバイト一致する。素材コピーのSHA256、寸法・透過、manifestからの通常／人物なし合成と付属プレビューの一致を検証した。人物なし時は旧版の背景と一致し、旧人物・影・ノートの残像は見られない。

Chromeで夕方と夜のPC 1440×900・1920×1080・1024×821、SP 390×844・430×932・768×1024を撮影した。レイヤー表示矩形は全て一致し、足元の接地、本や閉じたノートと手、カップの前後関係、ロゴ・ナビの可読性を確認した。スクリーンショットは `artifacts/evening-pose-v2/` と `artifacts/night-pose-v2/`。時刻の自動／手動4状態、昼と就寝後の回帰、通常・開発用ビルドを確認した。

見た目の最終確認点：夕方の髪・首・肩・袖の暖色縁取りは全景では窓辺の夕日に沿うが、拡大すると特にSPで強く見える。4セットの接地影は人物下端から作った控えめな近似で、窓台への密着感は全景では成立しているものの、細部は採否判断が必要。新人物には採用昼と比べ輪郭と筆致の微差がある。画像の色や輪郭はCSSで補正していない。

コミット・プッシュ・本番公開はしていない。
