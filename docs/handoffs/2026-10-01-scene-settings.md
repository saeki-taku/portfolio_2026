# 開発用シーン設定

右上の開閉パネルに季節・時間帯・天気、自動/手動、基準へ戻す操作を追加。未制作シーンは素材未対応を表示し、春昼晴れの採用画像を維持。自動時刻/天気連携は未実装と表示。選択変更はennui:scene-requestイベントに要求状態と表示中状態を分離して通知する。保存・実API呼び出しなし。
Astro devまたはENNUI_SCENE_DEV=1のビルドで表示。npm run build:dev-previewで4499用ビルド。通常npm run buildではボタン非表示。初回checkのprocess型エラーをimport.meta.envへ修正、最終checkと開発ビルド成功。パネル操作、未対応、自動時無効化、リセット、Escape、既存9画面テスト成功。
画像制作の一問一答：最初の夜は「凛がいる、灯りのある夜」で、窓辺で本を読むことに決定。夕方/夜は初回範囲、四季対応方針を縮小する決定ではない。
2026-10-04：描き直し版PCの外景・室内・凛・カップを個別に表示切替できる操作を同パネルに追加。SPは専用一枚絵のため無効化。
